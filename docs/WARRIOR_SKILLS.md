## Rules for every Warrior animation (the user, 2026-11-13)

1. **The near hand can ALWAYS carry a shield**, in every animation that exists and every one that will be made. The marks only say where the hand is and which way the item points; the page swaps the picture and its settings on the same marks (select "Warrior's near hand carries: a sword / a shield" in the Fight panel, remembered in the browser, like the mage's orb or book). The shield is ONLY a page-level swap on the same marks: **the pictures and the prompts are always designed for TWO SWORDS, both arms doing the same thing together** (the user, 2026-11-13, after ChatGPT mixed the hands up in the one-armed Sunder Strike prompt: "from now on please prepare prompts as all are designed for 2 swords"). With a shield chosen, the near arm just carries it in whatever pose it has.
2. **The sword is 0.5 long in ALL the Warrior's animations** (a share of the frame width, grip at 81%); the older 0.42 is gone (idle, hit, death, dodge, run, block and the Thunderclap Guillotine now say 0.5 in both hands). Item settings are per animation in the page, so each marks file carries it.
3. **A shield never has the hand drawn over it** (overlay off), 0.3 long, centred on the mark (grip at 50%).
4. Lightning and other blade effects follow the swords only: a shield carries none (`bladeSegs` skips it).
