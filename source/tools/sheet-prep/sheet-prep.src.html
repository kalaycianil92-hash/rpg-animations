Sheet Prep Tool

Turns a generated sheet of poses on a magenta background into a clean, aligned frame strip with a skin mask. Everything runs in this page. A sample idle sheet is loaded so you can see how it works.

1. Sheet

Sample: idle pack (reduced size)
Poses are read left to right, top to bottom, one pose per grid cell. Small specks and bits that belong to a neighbouring cell are dropped.

2. Output frame

Every frame is scaled by the same factor, taken from the size-reference frame, so poses keep their true proportions. Use "Rear heel" for packs where the back foot stays planted, and "Bottom centre" or "Body centre" for the death pack.

3. Check the frames

Preview the loop in each skin tone to check the recolour.

4. Save

Saving files is not available in this view. Right-click the strip above and choose Save image as.
